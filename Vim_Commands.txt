00:25 What is `gn`?
gn * Search forward for the last used search pattern, like with n, and start Visual mode to select the match.
If the cursor is on the match, visually selects it. If an operating is pending, operates on the match.
E.g., “dgn” deletes the text of the next match.
If Visual mode is active, extends the selection until the end of the next match. 

Note: Unlike n the search direction does not depend on the previous search command. ‘wrapscan’ applies.

‘incsearch’ (‘is’ * ‘nois’) * Hightlight first match * default on *

****** nvim best practices for copy/paste *** classic-copy-paste.nvim * Plugin ***********
To integrate Neovim with your system clipboard, add vim.opt.clipboard = "unnamedplus" to your init.lua or set clipboard=unnamedplus to your init.vim. This ensures all yank and delete operations interact directly with the OS clipboard. 
For precise control without overriding default behavior, use the + register explicitly with leader key mappings:
vim.keymap.set({'n', 'v'}, '<leader>y', '"+y', { desc = 'Yank to system clipboard' })
vim.keymap.set({'n', 'v'}, '<leader>p', '"+p', { desc = 'Paste from system clipboard' })
If system clipboard integration fails, ensure you have installed the necessary clipboard tools for your environment, such as xclip or xsel for X11, or wl-clipboard for Wayland. You can verify your setup by running :checkhealth inside Neovim. 
To avoid overwriting your system clipboard when replacing text in visual mode, map the paste command to delete without yanking:
vim.keymap.set('x', 'p', '"_dP', { desc = 'Paste without overwriting clipboard' })
For users who prefer standard OS shortcuts, the classic-copy-paste.nvim plugin maps Ctrl-C, Ctrl-V, and Ctrl-X to work seamlessly in terminal and GUI modes.
